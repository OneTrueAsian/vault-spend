# Security policy

## Reporting a security problem

If you find a way someone could see, change or delete another person's Vault Spend data, or get around a profile password, please tell us privately before posting about it anywhere.

1. Open the [Security tab](https://github.com/OneTrueAsian/vault-spend/security) of this repository.
2. Choose **Report a vulnerability**.
3. Describe what you found, the steps to see it happen, and the Vault Spend version (shown in Settings).

Only the maintainer can read the report. Please do not open a public issue for security problems, and do not include real financial data, passwords or recovery keys in your report.

## What to expect

- We will reply to say we have your report.
- We will tell you whether we can reproduce it and what we plan to do.
- Once a fix is released, we will credit you in the release notes if you would like.

## Supported versions

Only the latest release gets security fixes. Vault Spend checks for updates itself; please update before reporting, in case the problem is already fixed.
